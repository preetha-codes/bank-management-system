01 / Project overview

A practical application of C++ concepts

This project simulates essential banking operations through a menu-driven interface. It combines classes, objects, vectors, and file operations to organise account and transaction records.

About the project


Users can create bank accounts, deposit and withdraw money, check balances, search for accounts, and review transaction history. Local file storage allows saved records to be loaded again when the program restarts.

C++ Programming language
OOP Object-oriented design

04 / Application workflow

How it works

A straightforward sequence connects user input, account operations, and locally stored records.

01 — Input

The user selects an operation from the application menu.

02 — Process

The application validates the input and processes the request.

03 — Update

Account balances and transaction records are updated.

04 — Save

Records are stored locally for future program sessions.

Educational project disclaimer
This project is a programming demonstration, not a real banking service. It stores data in local plain-text files and does not implement production-grade authentication, encryption, or financial security controls. Use fictional information only.
